== Startup ==

User -> Main: launch GUI
Main -> Launcher: create + initialize AgentLauncherImpl
Launcher -> DbProvider: init ~/.koog/koog.db\n(create/migrate tables)
Launcher -> Orchestrator: initialize(projectPath=null)\n(boot without project)
Orchestrator -> Router: create AgentRouter\n(create agents + workspaces)
Launcher -> VM: create MainViewModel(launcher,\nTerminalSettingsRepository,\nAgentTabsStore,\nAgentStateStore)

note right of VM: Tabs + terminal state are restored from DB:\n- tabs list + active tab\n- session.conversation_history (events)\n- session.input_history (prompt history)\n- terminal output settings (filter + formatting)

== Project selection / restore ==

VM -> Orchestrator: loadProject(projectPath)
Orchestrator -> Context: loadProject(projectPath)\n(scan files -> currentFiles)
Orchestrator -> MCP: initializeForProject(projectPath)\n(collect MCP tool definitions)
Orchestrator -> Router: activate MCP structure\n(refresh workspaces + tools)

== Task processing (GUI) ==

User -> VM: submitTask(text, mode)
VM -> VM: addToInputHistory(text)\n(persist to session.input_history)
VM -> Client: processTask(task, mode, agentType, sessionId)

Client -> Orchestrator: routeTaskStreaming(task, sessionId, agentType)
Orchestrator -> Context: getContextForTask(task)\n(provides TaskContext.currentFiles)
Orchestrator -> Router: routeTaskStreaming(task, TaskContext)
Router -> EnhancedImpl: processStreaming(task, TaskContext)\n(default implementation path)

== EnhancedImplementationAgent (MCP plan + tool loop) ==

EnhancedImpl -> McpSelection: selectRelevantTools(task)\n+ extractParameters(...)
EnhancedImpl -> McpDecision: analyzeAndCreatePlan(...)
EnhancedImpl --> Client: AgentResponseChunk.Thinking("Plan: ...")\n(setting key: show_thinking_process)

loop tool execution
  EnhancedImpl -> Tools: readFile / listDirectory / regexSearch / writeFile / runCommand
  Tools --> EnhancedImpl: tool result
  EnhancedImpl --> Client: AgentResponseChunk.ToolCall(toolName, params,\nresult, success, durationMs)
  alt tool == writeFile AND success
    EnhancedImpl --> Client: AgentResponseChunk.FileDiff(path,\noldPreview, newPreview, +/-, ...)\n(setting key: show_code_diffs)
    EnhancedImpl -> EnhancedImpl: stop loop (avoid read/write oscillation)
  end
end

== UI mapping / rendering ==

Client --> VM: OutputEvent stream\n(Standard/Progress/ToolCallDetail/FileDiff/Thinking/...)
VM -> TermFilter: shouldShowAndFormat(key, settings, message)
VM --> Card: TerminalEventCard(event)\n(ToolCall/FileOp/FileDiff/Decision/Thinking)
Card --> User: rendered terminal feed
